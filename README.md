# Vyravo AI

Vyravo AI is a Next.js website and operations platform for AI automation services.

## Development

```bash
npm install
npm run dev
```

Useful checks:

```bash
npm run lint
npm run typecheck
npm run build
```

## Integrations

- Website AI chatbot: [OPENAI.md](./OPENAI.md)
- WhatsApp AI chatbot using the official Meta Cloud API: [WHATSAPP.md](./WHATSAPP.md)
- Existing integrations and architecture: [INTEGRATIONS.md](./INTEGRATIONS.md)
- Internal Knowledge Base: [KNOWLEDGE_BASE.md](./KNOWLEDGE_BASE.md)

Never commit `.env.local` or other real credentials. Use `.env.example` as the starting point for local configuration.
